# 🎨 GrafMaster

Генератор инфографики для маркетплейсов: карточки **900×1200** из фото,
Excel-характеристик и иконок. Сборка карточек, редактор (мини-Figma),
шаблоны «по образцу», онлайн-поиск фото, экспорт PNG/JPG/PDF/SVG/.fig.

## Запуск

**Десктоп-приложение (Windows):**
```bash
pip install -r requirements-desktop.txt
python src/main.py
```

**Веб-версия (в браузере):**
```bash
pip install -r requirements.txt
streamlit run web_app.py
```

## Возможности каркаса (Этап 1)

- 4 вкладки: Главная / Проект карточек / Шаблоны / Настройки
- Неоновая фиолетовая тема (тёмная) + светлая + режим для слабовидящих 👓
- Лента из 7 карточек товара с прокруткой и выбором
- Библиотека иконок (встроенные + место для своих)
- Окно «Товар по ссылке» (вставка ссылки на товар, подготовка к извлечению данных)
- Шрифты с кириллицей (Inter/Rubik/Manrope) — единый вид на любом Windows
- Кнопки экспорта: JPG / PDF / SVG / .fig / Вставить в Figma

## Структура

```
src/main.py                  — точка входа
src/grafmaster/app.py        — QApplication
src/grafmaster/theme.py      — темы (тёмная/светлая/слабовидящие)
src/grafmaster/ui/           — вкладки и виджеты
src/grafmaster/core/         — Excel, проект .gmproj, иконки
assets/                      — иконки и шрифты пользователя
docs/                        — документация
```
