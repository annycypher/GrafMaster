Можно ли создать программу генерации инфографики на связке Cline + DeepSeek + VS Code с установщиком для Windows?

Короткий честный ответ

Да, это реально, и почти всё решается бесплатными инструментами. Но сразу три важные поправки, чтобы не было ложных ожиданий:

  1. DeepSeek API не умеет искать и скачивать картинки. Это текстовая языковая модель. Она отлично работает с текстом (чистка названий, формулировки характеристик, написание SVG-кода), но найти и скачать фотографию товара на белом фоне она не сможет. Для онлайн-режима нужен отдельный сервис поиска изображений (ниже подробно).
  2. Paint не подходит. Это интерактивная программа, из кода вашего приложения её не запустить и не отдать ей команды. Вместо неё вся графика выполняется внутри самой программы библиотекой Pillow — это и есть «встроенный графический движок», бесплатный и полностью автоматический.
  3. Cline и VS Code нужны только на этапе разработки. В готовую программу они не попадают. Установщик будет содержать только ваше автономное приложение, а DeepSeek API — только в онлайн-режиме, как вы и написали.

Онлайн-режим — честно про поиск картинок

Повторим главное: DeepSeek API — текстовая модель, картинки не выдаёт. Для поиска фотографий товаров по названию нужен один из вариантов:

  • Bing Image Search API (Microsoft) — бесплатный уровень (порядка 1000 запросов в месяц). Надёжный вариант.
  • Google Custom Search JSON API — 100 бесплатных запросов в день.
  • SerpAPI и аналоги — удобно, но платно.
  • Парсинг маркетплейсов (WB, Ozon) — не рекомендую: нарушение правил сервисов, ломается, юридический риск.
  • Openverse — бесплатный поиск, но «товарных» фото там почти нет.

Рабочая схема онлайн-режима: программа ищет по названию N вариантов через API, показывает их пользователю, тот выбирает подходящее фото. Дальше программа проверяет углы изображения (белые ли) и при необходимости убирает фон локально через rembg. «Выбор человеком» резко повышает качество.

Иконки: ваши + генерируемые

  • Ваши иконки — папка assets/icons, используются как есть.
  • SVG — текстовый XML, генерируется кодом; DeepSeek отлично пишет SVG по описанию.
  • SVG → PNG нужного размера делает cairosvg.
  • Для расширения набора — свободные библиотеки иконок (Material Symbols, Feather, Bootstrap Icons).

Из чего соберётся установщик

  1. Python-приложение (интерфейс + Pillow + openpyxl).
  2. PyInstaller → один .exe (бесплатно, собирается на Windows).
  3. Inno Setup (или NSIS) → установщик setup.exe с иконкой и названием (бесплатно).
  4. В установщик входит только ваше приложение. Cline/VS Code там нет.
  5. DeepSeek API-ключ: «зашитый» в exe ключ можно извлечь. Честные варианты: (а) каждый клиент вводит свой ключ; (б) ваш ключ с шифрованием — не 100% защита; (в) свой сервер-посредник для проксирования запросов — правильно для крупных продаж, но это уже серверная часть.

Отдельная кнопка: интеграция в Figma

Да, это можно, и это хорошая идея. Готовая карточка — это просто PNG, а Figma вставляет изображения без труда. Три уровня интеграции — от простого к полному:

Уровень 1 — «полу-автоматический» (надёжен всегда)

Кнопка «Вставить в Figma»: приложение сохраняет карточки, кладёт активную карточку в буфер обмена (Pillow умеет это на Windows) и открывает Figma. Дальше пользователь жмёт Ctrl+V — карточка в макете. Самый простой вариант; подходит, если карточек немного.

Уровень 2 — свой плагин Figma (настоящая интеграция, рекомендую)

Плагин — маленькая бесплатная программа внутри Figma (JS, ~200–400 строк), ставится один раз (приватный плагин). Кнопка в приложении: (1) сохраняет карточки во временную папку; (2) поднимает локальный сервер localhost, раздающий картинки; (3) открывает Figma и запускает плагин.

Плагин через figma.createImageAsync() / figma.createImage() вставляет картинки, создаёт фреймы 900×1200 с именами товар_001…007, раскладывает их сеткой и выставляет настройки экспорта. Всё автоматически.

Честный нюанс: плагины работают в «песочнице» и не читают диск Windows напрямую. Передача картинок: локальный сервер (удобно, но localhost+https капризничает), диалог выбора файлов внутри плагина (работает в 100% случаев) или буфер обмена. Надёжная схема: кнопка = «сохранить карточки + открыть Figma», а плагин сам спрашивает папку.

Уровень 3 — Figma REST API (без плагина) — не подходит для этой задачи

Через личный токен API умеет создавать новый файл, читать документ, комментировать, работать с переменными. Но вставлять изображения, фигуры и текст в документ REST API не умеет — это делается только плагинами. Сам по себе REST API «наложить карточки» не сможет.

Что это даёт: карточки можно дорабатывать в Figma (брендинг, шрифты), шарить с клиентом, собирать мудборд из всех товаров. Плагин бесплатный и работает даже на бесплатном тарифе. К разработке добавит ~2–3 дня.

Редактируемый формат и редактор карточек («мини-Figma» в приложении)

Честно про «формат проекта Figma» (.fig): файл .fig — закрытый проприетарный формат (внутри ZIP + внутренний JSON), официально не документирован и меняется Figma без предупреждения. Генерировать редактируемый .fig извне — реверс-инжиниринг: ненадёжно и ломается при обновлениях. Официально поддерживаемый «редактируемый» формат, создаваемый вне Figma и импортируемый туда, — SVG (текст остаётся текстом, фигуры — векторными узлами). Figma импортирует SVG перетаскиванием — без всякого API.

Правильная архитектура:

  1. Свой формат проекта (JSON) — «микро-Figma» в приложении. Набор из 7 карточек = один файл проекта (.mcproj). Карточка = список слоёв: фон, фото товара, плашки, иконки, тексты, рамка. У слоя — позиция, размер, поворот, цвет, прозрачность, шрифт.
  2. Вкладка «Проект карточек»: слева список товаров; в центре — окно предпросмотра с плавным листанием по кнопкам «←» и «→» (карточки заранее отрисованы в превью-размере — листание мгновенное); справа — редактор слоёв (текст, шрифт, цвет, размер, положение выделенного элемента); кнопки «Сохранить» (пишет в файл проекта) и «Отмена» (откат к последнему сохранению). Предпросмотр перерисовывается в реальном времени (превью 360×480 — быстро).
  3. Экспорт «для Figma» — кнопка «Экспорт в SVG»: каждая карточка = SVG (тексты и фигуры редактируемые, фото товара встроено внутри). В Figma перетаскиваете — и всё редактируется. API Figma не используется, как вы и просили.
  4. Кнопка «Скачать .fig» (реально, но честно о риске). .fig — ZIP-архив: внутри document.json (слои, компоненты, стили), thumbnail.png и папка images/ с картинками. Формат частично расшифрован сообществом, есть библиотеки (npm figma-file), умеющие собирать такие файлы, — программа сможет сгенерировать .fig комплекта из 7 карточек. Но это реверс-инжиниринг неофициального формата: файл может не открыться после обновления Figma, сложные стили/компоненты поддерживаются не полностью. Поэтому рядом с «Скачать .fig» всегда будет «Скачать SVG» — официальный и стабильный путь.
  5. Роль DeepSeek (только свой ключ пользователя). Ключ вводится в настройках и хранится локально. DeepSeek — текстовая модель, картинки не рендерит, но в редакторе полезна: «Улучшить текст» (переписать характеристику), «Сгенерировать иконку» (SVG по описанию — сразу виден в предпросмотре), «Применить правку» (JSON-команда изменений для выделенного слоя), «Подобрать палитру». Редактирование вручную — у пользователя, DeepSeek автоматизирует текстовые и дизайн-решения.

Почему так, а не «всё внутри Figma»: Figma API исключён (он и не нужен), а .fig надёжно не генерируется. Свой JSON-проект + превью + редактор + SVG-экспорт — автономный редактор: правит карточки без интернета и без Figma, в Figma уезжает только готовый редактируемый SVG по желанию.

Что потребуется: интерфейс на PySide6 (Qt) — плавная анимация листания и перетаскивание слоёв мышью (Tkinter для этого слабоват). Бесплатно, установщик тяжелее на ~15–25 МБ. Сроки: редактор с вкладкой, листанием, слоями и кнопками Сохранить/Отмена — плюс 4–7 дней.

Поле поиска товара и конвертация картинок в PNG

  • В режиме «Онлайн» — отдельное текстовое поле поиска: вводите название товара → программа ищет фото через API поиска изображений (DeepSeek — текстовая модель и искать картинки не умеет, см. «Онлайн-режим») и показывает варианты.
  • Любую найденную картинку (JPG, WebP, TIFF, BMP, GIF и др.) программа сразу конвертирует в PNG — это делает Pillow, без доп. программ.
  • Дальше — проверка «белого фона» (анализ углов) и при желании удаление фона через rembg.
  • Готовый PNG попадает в проект карточек как слой «Фото товара» и работает в превью и редакторе как обычно.

Использование установленных Photoshop / CorelDRAW (локальный режим)

Да, можно. На Windows оба приложения управляются из кода через COM-автоматизацию — без облака, всё локально.

Photoshop (рекомендуемый из двух)

  • Официальный механизм скриптов (ExtendScript/JSX) + COM-интерфейс. Программа на Python вызывает установленный Photoshop: win32com → Photoshop.Application → выполняет JSX-скрипт (ps.DoJavaScript(...)): открывает файл, обработка (кадрирование, коррекция, резкость), сохранение PNG/JPG/PSD.
  • «Плагин» — это ваш JSX-скрипт: лежит рядом с программой, программа передаёт его в Photoshop. Дополнительно вызываются готовые Actions (.atn).
  • Честно: Photoshop должен быть установлен и лицензирован у пользователя; первый запуск долгий; при продаже нельзя требовать его у клиента — модуль опциональный.

CorelDRAW

  • COM-автоматизация + VBA-макросы (.GMS). Python управляет через CorelDRAW.Application и запускает VBA-макросы. Для растровой обработки — Corel PHOTO-PAINT (входит в комплект).
  • Честно: документация по COM скуднее, чем у Photoshop, API менее стабилен между версиями.

Как встраивается: опциональный движок для локального режима — пользователь выбирает в настройках «Pillow (встроенный, работает всегда)», «Photoshop» или «CorelDRAW». Программа передаёт фото и параметры → приложение обрабатывает → сохраняет → программа забирает готовый PNG и продолжает сборку карточки. Pillow — «запасной двигатель», работает всегда.

Сроки: модуль Photoshop/Corel — плюс 3–6 дней; не обязателен для первой версии.

Бесплатная векторная программа, которой можно задавать правила

Если не хотите привязываться к платным Photoshop/CorelDRAW — есть бесплатная альтернатива под схему «задай правила → редактируй → сведи → сохрани».

Inkscape (рекомендую) — бесплатный векторный редактор (GPL, Windows)

  • Родной формат — SVG; «сведение» = сборка слоёв (фото товара, плашки, иконки, тексты), как в нашем формате проекта.
  • Командная строка: inkscape --actions="select-all;export-filename:out.png;export-do" file.svg — открывает SVG, выполняет список команд, сохраняет PNG/PDF.
  • Python-расширения (inkex): скрипт-«правило» получает документ, меняет слои и атрибуты, возвращает результат.
  • Как рендерер: программа строит SVG → Inkscape конвертирует в PNG/PDF/JPG 900×1200. Бесплатен, автоматизируется, лицензия клиентам не нужна.

GIMP — бесплатный растровый редактор

  • Python-Fu (скрипты на Python) + пакетный режим: открыть → обработать (фон, коррекция, резкость) → сохранить. Подходит для подготовки фото.

ImageMagick — быстрый «движок сведения» без интерфейса

  • Чистый CLI: конвертация, масштабирование, наложение, вырезание фона по цвету, сохранение. Удобен для пакетной обработки.

Что выбрать: настройка «Движок обработки»: Pillow (встроенный), Inkscape (векторный SVG-конвейер), GIMP/ImageMagick (растровая), Photoshop/CorelDRAW (опционально). Сроки: интеграция Inkscape — плюс 2–4 дня.

Дополнительные связки инструментов для качественной сборки

На «качество» влияют: аккуратная замена фона (края без ореола), мягкие тени, чёткий текст, единая гамма. Связки — от простой к максимальной:

Связка A — «Всё встроено» (для первой версии, ноль установок)

  • Pillow (композиция: фото, плашки, текст, тени) + rembg (замена фона нейросетью на компьютере).
  • Текст — Pillow + шрифты с кириллицей (Inter, Manrope, Rubik).
  • Суперсэмплинг: рендер 2× (1800×2400) → уменьшение до 900×1200. Чёткие края и буквы.

Связка B — «Максимум качества, свободный софт»

  • Фон: rembg или BiRefNet (точнее края: волоски, блики); для белого фона — мгновенный flood-fill через Pillow/OpenCV.
  • Композиция: Pillow + OpenCV — мягкие тени, сглаживание краёв (feather), наложение с прозрачностью.
  • Текст: WeasyPrint — карточка по HTML/CSS (как в браузере): переносы, интервалы, тени, градиенты. Типографика уровня дизайнера.
  • Вектор-рендер по желанию: Inkscape.

Связка C — «Управляем внешними редакторами»

  • GIMP (Python-Fu), Inkscape (inkex), Photoshop/CorelDRAW (COM) — движки, которым приложение отдаёт правила и забирает результат. Актуально, если редакторы уже стоят.

Связка D — «Максимально точная вырезка» (GPU или запас времени)

  • Segment Anything (SAM2) + rembg — самые точные маски, идеальная замена фона на сложных фото.

Совет по качеству (бесплатно и сразу): суперсэмплинг 2×, мягкая тень под товаром, единая цветовая схема плашек, один фирменный шрифт — это 90% «дорогого» вида без платного софта.

Связка D — на чём это работает (железо)

  • Компоненты: PyTorch + модели SAM2 (tiny/small/base/large) + rembg. Модели скачиваются при первом запуске, дальше офлайн. Windows 10/11 x64.
  • Минимум (только CPU): 4 ядра (i5/Ryzen 5), 16 ГБ RAM, ~5 ГБ на диске. SAM2 tiny — 1–3 мин на фото, rembg — 1–3 сек.
  • Комфортно (NVIDIA GPU + CUDA): RTX 2060 и выше, 6+ ГБ VRAM — SAM2 tiny за 1–5 сек на фото.
  • RAM: 8 ГБ хватит для rembg, для SAM2 желательно 16 ГБ.
  • Размер программы: PyTorch с CUDA — это ~3–5 ГБ. В базовую версию не встраиваем: Связка D — опциональный модуль, ставится по требованию, сам определяет GPU и подключает нужную модель.
  • Рекомендация: по умолчанию rembg (работает на любом ПК); SAM2 включается автоматически, только если найдена видеокарта NVIDIA.

Стоимость связки и отдельные кнопки-движки

Стоимость инструментов — практически 0 ₽. Всё свободное ПО с разрешением коммерческого использования: Pillow, openpyxl, PySide6, PyInstaller, Inno Setup, rembg, Inkscape, GIMP, ImageMagick, WeasyPrint, OpenCV, SAM2 (Apache 2.0). Модели SAM2/rembg бесплатны.

Опционально платно: поиск картинок сверх бесплатных лимитов (Bing ~1000/мес, Google 100/день); DeepSeek за токены по своему ключу; Photoshop/CorelDRAW — покупает пользователь, если хочет этот движок; Figma — хватит бесплатного тарифа.

Отдельные кнопки-движки:

  • «Сборка: Pillow» — встроенный, работает всегда (базовый).
  • «Inkscape» — векторный рендер SVG→PNG/PDF; активна, если установлен Inkscape (бесплатно).
  • «Photoshop / CorelDRAW» — модуль для установленных редакторов (скрипты/COM); если программы нет — кнопка сообщает об этом.
  • «Вырезка фона: rembg» — нейросеть, работает на любом ПК (базовый).
  • «Вырезка фона: SAM2» — максимальное качество маски, отдельная кнопка; модуль по требованию (+3–5 ГБ), ускоряется на NVIDIA GPU.

Что такое SAM2: Segment Anything Model 2 — нейросеть Meta для выделения объектов на фото (открытая, Apache 2.0, локально). Понимает «что на фото главное», вырезает с точной маской даже на сложном фоне (шерсть, волосы, прозрачные предметы). Точнее rembg, но требует PyTorch и желателен GPU.

Сроки модулей: Inkscape +2–4 дня, PS/Corel +3–6 дней, SAM2 +3–5 дней.

Отдельный блок «Инфографика по образцу» (шаблон)

Да, можно — это «конструктор шаблонов»: один образец превращается в многоразовый шаблон, под который подставляются фото и тексты любых товаров.

Честно о сложности: автоматически превратить произвольный растровый образец в идеальные векторные слои с распознанным текстом — ненадёжно. Поэтому — надёжный гибрид:

  1. Загрузка образца — картинка из файла или из интернета (то же поле поиска).
  2. Авто-разбор образца: извлечение палитры (цвета плашек, фона, текста) и поиск зон: область фото товара (крупный однородный прямоугольник через контуры OpenCV), плашки, рамки, границы текстовых блоков.
  3. Векторные слои по образцу — найденные зоны становятся слоями проекта (плашки, рамки, текстовые поля, иконки). Текст берётся из Excel, а не из картинки — надёжнее распознавания.
  4. Доработка в редакторе — зоны правятся мышью и сохраняются как шаблон.
  5. Массовое применение — к шаблону подставляются фото (папка/интернет) и характеристики из Excel; каждая карточка сохраняется 900×1200 (PNG/JPG/PDF).

Итог: один образец → готовый шаблон → сколько угодно товаров одной кнопкой. Сроки: +3–6 дней.

Честные ограничения и риски

  • Онлайн-режим — самый хрупкий блок: сторонние API, лимиты, изменения политик. Режим «Из папки» работает всегда.
  • Фото товаров — чужие изображения. Перед продажей карточек проясните права (свои съёмки или лицензии). То же с иконками.
  • 900×1200 — пропорция 3:4, в целом подходит для WB/Ozon; сверьтесь с актуальными требованиями площадки.
  • Качество онлайн-поиска зависит от точности названий. Выбор пользователя смягчает.
  • Большие партии — обрабатывать пакетами/очередью, чтобы программа не «подвисала».

Сроки и стоимость

  • Инструменты почти все бесплатны. Платно при желании: ключи поиска картинок сверх лимитов и DeepSeek API за токены (копейки).
  • MVP (каркас + режим «Из папки» + Excel + оверлеи + JPG/PDF): 1–2 недели. Генерацию кода берёт на себя связка Cline + DeepSeek.
  • Установщик и отладка на «чистой» Windows: ещё 2–4 дня.
